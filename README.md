I am pursuing an **MS in Data Science at the Institute of Management Sciences (IMSciences)** after completing a **BS in Statistics from the University of Peshawar**. That statistical foundation shapes how I approach data: I pay attention to assumptions, preprocessing, validation, uncertainty, and whether a result is genuinely supported by evidence.

My work is methodology-driven rather than limited to one industry. I apply data analysis, statistical learning, machine learning, and AI across different problem settings, including EEG and biomedical data, knowledge graphs, commercial analytics, and sensor-based systems. I am also exploring reliability-oriented modelling for aerospace and predictive-maintenance applications. Across these areas, my priorities remain consistent: clear problem formulation, careful evaluation, interpretable results, and reproducible workflows.

## How I Approach a Project

I begin with the question, the available evidence, and the limits of the dataset. I then build a traceable workflow from data collection and cleaning through exploration, modelling, and evaluation. When comparing models, I look beyond a single accuracy value and consider validation design, class imbalance, error patterns, interpretability, and whether the result can be reproduced. I finish by communicating the findings through clear notebooks, visualizations, dashboards, reports, or interactive applications. This process helps me work across different application domains without losing statistical discipline.

## Featured Projects

### [Pakistani Fashion Intelligence](https://github.com/aqibhanifai/Pakistani-Fashion-Intelligence)

An end-to-end competitive price analytics project covering 281 products from three Pakistani fashion brands. The workflow combines web scraping, Python data cleaning, PostgreSQL analysis, Open-Meteo weather context, an interactive Excel dashboard, a report, and a presentation.

`Python` `Pandas` `PostgreSQL` `Web Scraping` `API` `Excel`

### [EEG Seizure Prediction](https://github.com/aqibhanifai/EEG-Seizure-Prediction)

An experimental machine-learning and deep-learning workflow for seizure-related EEG analysis. It covers signal preprocessing, feature engineering, model evaluation, cross-validation, statistical analysis, learning curves, and comparison tables while avoiding clinical claims.

`Python` `EEG` `MNE` `Scikit-learn` `TensorFlow` `PyTorch`

### [Explainable Brain Tumor Knowledge Graph](https://github.com/aqibhanifai/brain-tumor-knowledge-graph)

A compact knowledge-graph prototype connecting brain-tumor subtypes, genes, and drugs through evidence-aware relationships. The repository includes graph construction, interpretable reasoning paths, structural evaluation, visualizations, an ablation design, and clearly stated limitations.

`Python` `Jupyter` `Knowledge Graphs` `Graph Analytics` `Explainability`

### [NeuroKG Explorer](https://github.com/aqibhanifai/neurokg-explorer)

A simulation-based web application for exploring relationships among neurological disorders, genes, drugs, and EEG-like signals. It combines structured biomedical information with an interactive interface built using TypeScript and Vite.

`TypeScript` `Vite` `Node.js` `Knowledge Graphs` `Data Visualization`

### [IBM Data Analyst Capstone Project](https://github.com/aqibhanifai/IBM-Data-Analyst-Capstone-Project)

A documented analysis of current and desired technology trends using the 2025 Stack Overflow Developer Survey. The notebook demonstrates data collection concepts, wrangling, exploratory analysis, statistical summaries, visualization, and dashboard-ready outputs.

`Python` `Pandas` `NumPy` `Matplotlib` `Jupyter` `Data Analytics`
